# 社会保障審議会（年金部会）発言データベース

厚生労働省の[社会保障審議会（年金部会）一覧](https://www.mhlw.go.jp/stf/shingi/shingi-hosho_126721.html)を2026年9月24日に確認し、一覧から直接リンクされた議事録を発言単位で整理しました。委員だけでなく、部会長、事務局、参考人など、議事録で発言者として示された人・役職を含みます。

## 収録範囲

- 一覧上の会合等：138件
- 議事録リンクがある会合：122件、議事録：123件（HTML 80件、TXT 43件）
- 抽出した発言：8,851件（2002年1月16日～2025年6月30日）
- 議事録リンクのない行：16件。これらの発言は収録していません。`議事録リンク未掲載の会合.csv`を参照してください。

一覧に「議事要旨」しかない場合は、全文発言を推測して追加していません。議事録自体が原文途中で終わっている箇所も原文どおりです。例えば2024年12月3日回の末尾は厚労省掲載文が「どうもありがとうござい」で終わります。

## ファイル

- `年金部会_発言データベース.sqlite`：SQLiteデータベース。会合・出典・発言の3表と全文検索表を含みます。
- `年金部会_発言一覧.csv`：発言を日付・回次・発言者・本文・原文URLとともに並べた表です。Excelでも開けます。
- `議事録リンク未掲載の会合.csv`：一覧にはあるものの議事録リンクがない行です。
- `抽出確認.json`：議事録ごとの抽出件数と取得状況です。
- `年金部会_更新.py`：公開一覧からデータベースを作り直すスクリプトです。実行にはPythonと`lxml`、インターネット接続が必要です。

## データベースの読み方

`meetings`は会合、`sources`は議事録URL、`utterances`は発言です。`utterances.sequence`は議事録内の発言順です。`speaker_label`は原文の発言者表記、`speaker_key`は表記から「委員」「部会長」などの役職語を機械的に除いた検索補助欄です。役職だけの発言者表記や同姓の人を人物として同定するものではありません。人物別の厳密な集計には、原文・委員名簿との照合が必要です。

たとえばSQLiteで次のように検索できます。

```sql
SELECT m.date, m.meeting_label, u.sequence, u.speaker_label, u.body, s.url
FROM utterances AS u
JOIN meetings AS m ON m.id = u.meeting_id
JOIN sources AS s ON s.id = u.source_id
WHERE u.body LIKE '%遺族年金%'
ORDER BY m.date, u.sequence;
```

`utterances_fts`には日本語の部分文字列検索用の3文字単位の索引があります。3文字以上の語であれば、`WHERE body MATCH '遺族年金'`として検索できます。

発言境界は議事録中の「○」「〇」などの発言者記号から自動抽出しています。123件すべてで発言を検出し、HTMLの案内文の混入と日付形式を点検済みです。引用や厳密な分析には各発言に付いた原文URLで確認してください。
